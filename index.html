Attention

$$\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)V$$

Test me first

Goal: let token \(i\) pull information from tokens \(j \le i\).

Query \(q_i\): what token \(i\) looks for.

Key \(k_j\): what token \(j\) offers.

Value \(v_j\): what token \(j\) hands over.

Score \(S_{ij} = q_i\cdot k_j\): how well \(k_j\) matches \(q_i\).

Weight \(A_{ij}\): softmax of the scores over \(j\).

Output \(o_i = \sum_j A_{ij}\,v_j\): weighted sum of values.

Heads: run \(H\) attentions in parallel, each on \(d_{model}/H\) dimensions, then concatenate.

  1. Project the input three ways
    $$Q = XW_Q,\quad K = XW_K,\quad V = XW_V \qquad X\in\mathbb{R}^{T\times d_{model}},\;\; Q,K\in\mathbb{R}^{T\times d_k},\;\; V\in\mathbb{R}^{T\times d_v}$$
    WhyRow \(i\) belongs to token \(i\). Separate \(W_Q\), \(W_K\): what a token looks for can differ from what it offers.
  2. Score every query against every key
    $$S = QK^\top \in \mathbb{R}^{T\times T},\qquad S_{ij} = q_i\cdot k_j = \sum_{c=1}^{d_k} Q_{ic}K_{jc}$$
    Rows = queries, columns = keys. In code: "... q d_k, ... k d_k -> ... q k".
  3. Divide by \(\sqrt{d_k}\)
    $$\tilde S = \frac{QK^\top}{\sqrt{d_k}}$$
    Why Problem: unscaled scores grow with \(d_k\). Softmax goes one-hot, gradient \(\approx 0\).
    Setting: components of \(q\), \(k\) independent, mean 0, variance 1. Then \(\mathrm{Var}(q_ck_c) = \mathbb{E}[q_c^2]\,\mathbb{E}[k_c^2] = 1\). $$\mathrm{Var}(q\cdot k) = \sum_{c=1}^{d_k}\mathrm{Var}(q_ck_c) = d_k \;\;\Longrightarrow\;\; \mathrm{Var}\!\left(\frac{q\cdot k}{\sqrt{d_k}}\right) = 1$$
  4. Mask the future
    $$M_{ij} = \begin{cases} 0 & j \le i \\ -\infty & j > i \end{cases}$$
    WhyBefore softmax: \(e^{-\infty}=0\), rows still sum to 1.
    After softmax: rows sum to less than 1.
  5. Softmax each row
    $$A_{ij} = \frac{\exp(\tilde S_{ij} + M_{ij})}{\sum_{j'}\exp(\tilde S_{ij'} + M_{ij'})},\qquad \sum_j A_{ij} = 1$$
    Row \(i\) of \(A\): how token \(i\) splits its attention.
  6. Blend the values
    $$O = AV \in \mathbb{R}^{T\times d_v},\qquad o_i = \sum_j A_{ij}\,v_j$$
  7. Multi-head
  8. Split into \(H\) heads
    $$d_k = d_v = \frac{d_{model}}{H},\qquad XW_Q \in \mathbb{R}^{T\times d_{model}} \;\to\; Q^{(h)} \in \mathbb{R}^{T\times d_k},\quad h = 1..H$$
    Head \(h\) takes columns \((h-1)d_k\) to \(hd_k\). Same split for \(K\) and \(V\). In code \(H\) is a batch dimension.
  9. Attend in each head
    $$O^{(h)} = \mathrm{softmax}\!\left(\frac{Q^{(h)}K^{(h)\top}}{\sqrt{d_k}} + M\right)V^{(h)} \in \mathbb{R}^{T\times d_k}$$
    WhyOne softmax gives each token one distribution. \(H\) heads give it \(H\) distributions, so it can attend to different tokens for different reasons.
    Same mask \(M\) for every head.
  10. Concatenate and project
    $$O = \big[\,O^{(1)} \;\cdots\; O^{(H)}\,\big]\,W_O \in \mathbb{R}^{T\times d_{model}},\qquad W_O \in \mathbb{R}^{d_{model}\times d_{model}}$$
    WhyConcatenation keeps heads in separate columns. \(W_O\) mixes them.
    Parameters: \(W_Q, W_K, W_V, W_O\), so \(4\,d_{{model}}^2\) with no bias. Independent of \(H\).

Your mask is torch.tril(torch.ones((T, T), dtype=torch.bool)). True = may attend, hence ~mask.

Write the full attention formula with the shape of every intermediate.

\(Q,K\in\mathbb{R}^{T\times d_k}\), \(V\in\mathbb{R}^{T\times d_v}\). \(QK^\top/\sqrt{d_k}\in\mathbb{R}^{T\times T}\), add \(M\), softmax over the last axis gives \(A\in\mathbb{R}^{T\times T}\), then \(AV\in\mathbb{R}^{T\times d_v}\).

Where does \(\sqrt{d_k}\) come from, and what breaks without it?

With unit-variance components the dot product has variance \(d_k\), so its typical size is \(\sqrt{d_k}\). Unscaled, large scores push softmax towards one-hot and the gradient through it goes to zero.

Why apply the mask before the softmax instead of zeroing weights after it?

\(-\infty\) before the softmax removes those terms from the normaliser, so the allowed weights still sum to 1. Zeroing afterwards leaves rows that sum to less than 1.

With \(H\) heads, what is the shape of \(Q\) per head, and how many weights does the layer have?

\(Q^{(h)}\in\mathbb{R}^{T\times d_k}\) with \(d_k = d_{model}/H\). Weights: \(4\,d_{model}^2\) with no bias (\(W_Q, W_K, W_V, W_O\)), independent of \(H\).
